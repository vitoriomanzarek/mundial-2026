# Mundial 2026

Página web visual e interactiva del Mundial 2026. Diagrama de grupos, partidos, bracket eliminatorio y evolución de puntos.

## Stack

- Next.js 14 (App Router) + TypeScript
- Tailwind CSS
- Framer Motion (animaciones)
- Recharts (gráficas)
- Datos: JSON estático en `src/data/`

## Estado

Proyecto en construcción. Ver:
- `ARCHITECTURE.md` — diseño técnico y decisiones.
- `data-schema.md` — estructura de los datos.
- `CLAUDE.md` — instrucciones para el ejecutor (Claude Code).

## Desarrollo

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).

## Deploy

Conectado a Vercel — cada push a `main` redeploya.
